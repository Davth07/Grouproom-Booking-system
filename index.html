Välkommen till Grupprumsbokningsystemet

Här är det möjligt att boka grupprum. Vänligen använd länkarna ovan för att se tillgängliga rum, boka ett rum eller kontakta oss för mer information.

Boka rum

För att boka ett grupprum, tryck på "Boka" länken längst upp på sidan eller klicka här. Där skriver du in dina uppgifter och väljer datum och tid.

Därefter kan du se dina aktiva bokningar på sidan "Bokningar". Tryck på "Bokningar" länken längst upp på sidan. Eller klicka här.

Om du vill se mer om varje rum, klicka på "Rum" länken längst upp på sidan. Eller klicka här.
